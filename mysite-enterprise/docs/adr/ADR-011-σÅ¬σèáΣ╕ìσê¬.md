# ADR-011：衝突時一律「再加一層」，不移除舊路徑

- 日期：2026-11-02（第二輪追加）
- 狀態：**已接受**（會議 11 分鐘，結論一致）

## 決策
1. 不刪除任何既有程式、註解、設定或文件段落。
2. 新功能一律以新檔案或檔案尾端「追加區」實作。
3. 既有行為與新行為衝突時，兩者並存，由 A/B/C 分流、隨機數或呼叫順序決定誰生效。
4. 為了解決「雙載入」而新增的橋接層，不得移除原本的雙載入。

## 理由
移除需要回歸測試；加一層不需要（因為沒人測新層）。

## 後果
- 入口從 1 個變 2 個（`app.js`、`extras-boot.js`）。
- 事件監聽從 N 個變 N+5 個。
- `TECH_DEBT.md` 從 28 筆成長到 56 筆，盤點本身再新增 1 筆。

## 反對意見
無（會議紀錄只有一句「先不要動，再加一層 abstraction」）。
