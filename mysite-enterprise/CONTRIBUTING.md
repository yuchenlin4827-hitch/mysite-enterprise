# 貢獻指南

## 三條規則

1. **只能加在檔案最下面。** 不要改上面的行，包含明顯寫錯的註解。
2. CSS 新規則請加 `!important`，以免被上面的蓋掉（上面的也加了 `!important`，所以由順序決定，這沒關係）。
3. 遇到重複的功能，**不要刪舊的**，請新增一個檔案並在 `extras-boot.js` 再 init 一次。

## 檔案去哪找

| 想做的事 | 請先讀 | 然後 |
|---|---|---|
| 改 API | `api-client.js` | 再新增 `api-client-v4.js` |
| 改主題 | `theme.js` | 再新增一個來源 |
| 改開機 | `app.js` | 不要改，改 `extras-boot.js` |
| 改設定 | `config.js` | 記得 `.env.example` 也要加一行（不會生效） |
| 改技術債 | `TECH_DEBT.md` | 在表格最下面加一列，順手更新「下次會議結論」 |

## PR 檢查清單

- [ ] 沒有刪除任何一行
- [ ] `npm test` 顯示 47 passed
- [ ] `npm run lint` 沒有紅字（後面有 `|| true`）
- [ ] 新增的債已登記編號，且編號沒有跟別人重複（上次重複過，兩邊都留著）
- [ ] 沒有順手修好任何東西

## 例外
如果你真的修好了一個 bug，請在同個 PR 補一個功能把複雜度加回來，以維持平衡。
